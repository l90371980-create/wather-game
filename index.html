WATHER GAME

Cada gota conta!

Projeto educativo sobre o uso consciente da água.

📖 COMO JOGAR

1. Explore o labirinto usando as setas do teclado ou WASD.

2. Encontre a caixa de vidro e leia a pergunta.

3. Acerte a resposta para liberar a chave inglesa.

4. Encontre e feche as 4 torneiras de cada fase.

5. Feche todas as torneiras para avançar.

6. Complete as 3 fases para vencer o jogo.

Regras

  • Você precisa da chave inglesa para fechar as torneiras.
  • Respostas erradas podem ser tentadas novamente.
  • Não é possível atravessar as paredes do labirinto.
  • O objetivo é conscientizar sobre o desperdício de água.
